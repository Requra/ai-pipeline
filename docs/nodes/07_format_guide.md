# Node Guide: Format Node
**Status**: `[UNASSIGNED]`  
**Owner Role**: Backend Developer / API Engineer

## 1. Description & Vision
The **Format Node** is the final step in the AI pipeline. It assembles all results (summaries, requirements, user stories) into a clean, structured JSON response and determines the final status of the process.

**Vision**: A robust final stage that guarantees the output is both technically sound (valid JSON) and semantically complete.

## 2. Current Implementation (`format.py`)
- **Logic**: 
    - Checks for `error`, `user_stories`, and `classified_requirements`.
    - Infers `status`: `success`, `partial`, or `error`.
- **Input**: `state.get("error")`, `state.get("user_stories")`, `state.get("classified_requirements")`.
- **Output**: `{"status": str, "error": str}`.

## 4. Operational Guidelines
- **Integrity**: This node is responsible for ensuring that if any previous node failed, a clear error message is still returned to the user.
- **Independence**: It must not call any LLMs. This is a purely logical formatting step.
- **Transparency**: Log the final status and error count for analysis.

## 5. Verification Checklist
- [ ] Does it return `success` if all major components exist?
- [ ] Does it return `partial` if some data was extracted but an error occurred?
- [ ] Is the final output valid JSON that can be consumed by the frontend?
- [ ] Does it include the `error` message if one was generated by previous nodes?
